Manual rápido

Versão para iPhone baseada no manual oficial (Rev 3.0). Toque em vários botões ao mesmo tempo, como no aparelho.

Tocar acordes

Os 7 botões tocam os 7 acordes do tom (em Dó: C, Dm, Em, F, G, Am, B°). Fileira de cima = 2, 4, 6; de baixo = 1, 3, 5, 7.

Segure acorde + joystickMuda a qualidade do acorde (8 direções)
Segure 1 + toque 6Acorde com baixo invertido (Am/C)
Acorde + Inversão: Fund. → 1ª → 2ª
Acorde + / Oitava só desse botão −1 / +1 (±2)
Acorde + joystick por 1 sChord Lock (trava a modificação; repita para destravar)

Botões de menu

KEY← → tom · ↑ ↓ oitava geral · girar roda = Attack
SOUND← → timbre · ↑ efeitos/ajustes · roda = Release · segure + botão 1–7 = timbre rápido
MODE← → modo · ↑ BPM · ↓ velocidade/rate do modo · roda = Filtro · segure + botão = modo rápido · 3 toques = tap tempo
Segure menu + cliqueRandomize (som, tudo ou padrão)

Toque rápido abre o menu; clique no joystick volta/fecha. Na lista de efeitos: ← → navega, ↑ muda, ↓ volta o valor.

Modos (vermelho + botão)

1 PlayAcorde inteiro
2 StrumNotas em rasgueado (SLO/MED/FST)
3 LeadNota única; joystick move ±oitava/semitom
4 DroneO acorde sustenta até trocar
5 ArpArpejo no BPM. Em Arp: vermelho + 1–5 = padrão, + 7 = camadas
6 RepeatRepete o acorde no tempo
Drums(← →) Bateria. Vermelho + 1–6 = kit. Segure tambor + joystick = rolo automático
Beat(← →) 7 estilos × 8 variações. Toque o estilo para tocar/parar; segure + ↑↓ = variação; clique = gravar o beat no looper
Seq(← →) Sequenciador de até 16 acordes
Mixer(← →) Aparece quando o looper tem áudio

Looper (6 faixas, ~20 s)

Funciona em Play, Strum, Lead, Drone, Arp, Repeat e Drums, sem segurar acorde. A faixa da linha de ícones da tela: ● 1–2, ■ 3–4, ▲ 5–6, e ▶/❚❚ = transporte.

Joystick ← →Escolhe a faixa · ↓ vai ao play/pause · ↑ volta à faixa 1
Clique1º arma (ARMED) · 2º grava · 3º para (no modo livre)
Faixa 1LOOP LEN = FREE: começa a gravar quando você toca; clique para fechar o loop. Em 1–8 BARS: contagem de 4 tempos e para sozinho
Faixas 2–6Começam no próximo início do loop e gravam exatamente uma volta
Clique no ▶Pausa/retoma tudo (efeito tape-stop)
Segurar clique 0,7 sApaga a faixa (no ▶ apaga tudo)

LOOP LEN e METRO ficam em → ↑ (lista de efeitos). Sem overdub nem desfazer, como no aparelho.

Sequencer (modo SEQ)

Parado: toque acordesCada toque vira um passo (com o joystick, salva o acorde modificado)
CliquePlay/stop (com loop tocando, começa no início do loop)
← →Move o cursor (tocar um acorde sobre um passo o substitui)
↑Remove os últimos 4 passos
Segurar cliqueCorta tudo a partir do cursor
→ ↓Duração do passo (1/16 a 1/1)
Sair tocandoGrava a sequência na próxima faixa vazia do looper

Mixer

← → escolhe a faixa, ↑ ↓ volume, clique = mute.

Volume

Arraste a roda serrilhada na borda de cima para os lados.

O que não está nesta versão

Chord Hiro, Ear Trainer, Tuner, Auto-Drum, microfone (Sampler/Vocoder), Companion App, Presets e MIDI. Os timbres “gravados” do aparelho são aproximados por síntese.
